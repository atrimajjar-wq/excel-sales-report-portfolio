Excel Sales Report

Project Overview

This project demonstrates an Excel sales report using fictional sample business data. It summarizes revenue and profit and presents product sales in a chart.

Skills Demonstrated

Organizing sales data in an Excel table

Calculating revenue using formulas

Calculating profit using formulas

Using SUM, COUNTA, and AVERAGE

Creating a sales summary

Creating a column chart

Formatting a worksheet for readability

Key Results

Total Revenue: 3,085

Total Profit: 980

Total Orders: 5

Average Order Value: 617

Files

Sales_Report.xlsx — Excel workbook containing the sample data, formulas, summary, and chart.

Tools

Microsoft Excel

Note

All data is fictional and intended for demonstration purposes.
